A certificate is a signed statement

Certificate:
    Subject: CN = localhost
    Issuer:  CN = My Lab CA
    Validity
        Not Before: Sep 22 10:47:35 2026 GMT
        Not After : Sep 22 10:47:35 2027 GMT
    Subject Public Key Info:
        Public-Key: (2048 bit)          ← the server's public key
    X509v3 extensions:
        Basic Constraints: CA:FALSE
        Extended Key Usage: TLS Web Server Authentication
        Subject Alternative Name: DNS:localhost
    Signature (sha256WithRSAEncryption)   ← by the issuer's private key

A public key, a name, two dates, and a signature. No secrets inside.

    What the padlock does not promise

    • Not that the site is honest. Phishing sites have padlocks.
    • Not that it is the site you meant. A lookalike name gets one too.
    • Not that the code behind it is safe. Only the pipe is checked.
