HOTP: a counter, a MAC, six digits

  1. counter08 bytes
  2. HMAC-SHA1cc93cf18 … e4b020 bytes
  3. offsetlast byte & 0x0F = 0
  4. 4 bytescc93cf18 & 0x7fffffff1 284 755 224
  5. mod 10⁶755224

One line of code each. Every number is printed in RFC 4226.

TOTP: let the clock be the counter

counter = ⌊ unix_time / 30 ⌋

Both sides can compute it. Nobody sends anything.

Wrong clock, wrong code.

What TOTP does not stop

  • A server breach. The secret is on the server.
